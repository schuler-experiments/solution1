## File Compilation Reference

### Core Module
```bash
fpc solution1/taskmanager.pas -obin/taskmanager.ppu
```

### Compilation with Examples
```bash
# Basic demo
fpc solution1/solution1.pas -obin/task_manager -O1 -Mobjfpc

# Extended features
fpc solution1/solution2.pas -obin/task_manager_ext -O1 -Mobjfpc

# Boards demo
fpc solution1/solution15.pas -obin/boards_demo -O1 -Mobjfpc

# See QUICK_START_GUIDE.md for all compilation commands
```
